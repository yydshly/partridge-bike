# 鹧鸪骑单车 · 3D 互动

一只圆滚滚的鹧鸪，骑着一辆青绿色复古单车，穿过黄昏的草场。

纯手写 WebGL 渲染，无任何外部依赖与网络请求，**双击 HTML 即可运行**。

![桌面效果](preview/desktop.png)

## 运行

双击 `partridge-bike-3d.html`，或把它拖进浏览器。

需要浏览器支持 WebGL（建议开启硬件加速）。

## 操作

| 操作 | 桌面 | 触屏 |
| --- | --- | --- |
| 环绕视角 | 拖拽画面 | 单指拖拽 |
| 推拉镜头 | 滚轮 | 双指捏合 |
| 加减速 | `W` / `S`（或 ↑ / ↓） | 拖动速度滑杆 |
| 左右转向 | `A` / `D`（或 ← / →） | 右下角 ◀ ▶ |
| 跳跃 | `空格` | 右下角「跳」 |
| 暂停 | `P` 或播放键 | 播放键 |
| 切换视角 | `C` 或 环绕/侧视/前视/跟随 | 视角按钮 |
| 切换昼夜 | `N` 或 时间按钮 | 时间按钮 |
| 复位 | `R` 或 复位按钮 | 复位按钮 |

双击画面可回到默认环绕视角；左下角控制条提供完整的鼠标操作入口。

## 场景与动画

- **手写迷你 WebGL 引擎**：矩阵变换、程序化低多边形几何、方向光 + 半球环境光、雾、平面软阴影、点精灵粒子、全屏天空着色器。
- **鹧鸪角色**：圆胖的身体、带斑点的胸羽、红眼圈、橙色喙、羽冠、扇形尾羽；两段式腿部 IK 让双脚始终踩在旋转的脚踏上。
- **单车**：车轮/辐条、挡泥板、链条与牙盘、曲柄、车铃、车灯、藤编车篮和会随骑行轻晃的花。
- **骑行联动**：轮速与踏频联动，身体随踏频起伏，头部点头，尾巴左右摆动，翅膀在把手上轻轻颤动；转向时车身侧倾，跳跃时张开翅膀并扬起尘土。
- **世界**：起伏草场、围栏、松树与阔叶树、远山、飞鸟群、黄昏的太阳、夜色中的月亮/星空/萤火虫，以及随风飘浮的尘埃。
- **三套昼夜调色盘**：黄昏 / 白天 / 夜晚，颜色、太阳方向、雾、星光和萤火虫平滑过渡。
- **响应式**：桌面和手机分别构图，移动端自动拉远镜头并显示触屏骑行键。

## 文件

```
partridge-bike-3d.html   单文件成品，直接运行
src/engine.js            迷你 WebGL 引擎（数学、几何、着色器、渲染器）
src/scene.js             草场、单车、鹧鸪、飞鸟的程序化建模
src/app.js               物理、骑行动画、相机、昼夜、UI 交互
src/style.css            界面样式
src/index.template.html  页面骨架
build.mjs                把 src 内联生成单文件
preview/                 效果截图
```

修改 `src/` 后，运行：

```bash
node build.mjs
```

即可重新生成 `partridge-bike-3d.html`。

## 性能提示

- 渲染分辨率自适应，设备像素比上限 2×。
- 物理与动画基于 `requestAnimationFrame`，像素与相机平滑都做了帧率无关处理。
- 若在低端设备上偏卡，可将 `src/scene.js` 里的草地数量（`buildGrass` 循环中的 `3200`）调低，然后重新构建。
