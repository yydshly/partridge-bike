## 口径与局限

- 四次测试使用同一条提示词，由用户确认。
- 展示各自最终成品，未控制运行环境、工具、迭代次数与中间修复过程；不标注一次生成。
- 前三份耗时来自任务界面；Opus 的约 2 分钟来自用户说明。任务耗时不等同于纯模型推理延迟；Codex 任务包含检查和部署等环节。
- 未提供的数据保留为 null，网页显示未提供，不按零处理。
- DeepSeek 账单窗口为近 30 天，用户确认其全部消耗来自本次任务。
- 混元 4 使用 WorkBuddy 的 Hy4 preview，任务截图显示 25m12s；用户确认使用免费额度，界面标注夜间免费。costCny=0 记录本次用户支出，不代表常规 API 定价。
- 单次成品观察，不是统一条件下的基准测试。

模型名称与设置来自用户截图或说明，不推断后端模型标识。DeepSeek Tokens 未提供输入、输出及缓存拆分。账单截图与任务截图保存在 evidence/。
